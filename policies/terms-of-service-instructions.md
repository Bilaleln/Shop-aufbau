# Terms of Service: manual creation (the API cannot create policies)

1. Shopify admin → **Settings → Policies → Terms of service → Create from template**.
2. Before saving, make these corrections in the generated text:
   - **Intro / operator:** wherever the template names the store as "Falurana", change it to
     **FALUNARA**. In the first paragraph, identify the operator, for example:
     > This website is operated by M and B the MBFs LLC, doing business as FALUNARA ("FALUNARA," "we," "us," or "our").
   - **Contact section:** email **badush71@proton.me**; postal address
     **M and B the MBFs LLC (FALUNARA), 7901 4th St N Ste 300, St. Petersburg, FL 33702, United States**.
     Remove any empty "phone" wording (e.g. "call  or"). Do **not** add a phone number.
   - **Website:** falurana.com (the domain stays as is).
   - Do not describe the address as a store, warehouse, or return center.
   - Search the generated text for "Falurana", "[", "{{", and any empty fields, and fix them.
   - Leave Shopify's standard legal clauses as they are. If the template has a governing-law field, it
     will normally use the store address (Florida). Confirm this with your legal adviser.
3. Save. The link will appear automatically in the footer policy row.

Consistency: the template's refund and shipping language refers to separate policies, so it does not
contradict them. If the generated text states any specific refund window or shipping time, delete that
sentence and refer to the Return & Refund Policy / Shipping Policy instead.
